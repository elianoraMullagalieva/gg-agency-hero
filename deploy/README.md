# Выгрузка сайта на хостинг

## Разовая настройка

```bash
./deploy/setup.sh
```

Скрипт спросит хост, порт, логин, пароль и папку на сервере.
Пароль вводится скрытым вводом и сохраняется в `deploy/secrets.env`
с правами 600. Этот файл добавлен в `.gitignore` и в git не попадёт.

## Деплой

```bash
./deploy/deploy.sh
```

Заливает всю папку `hero-arc` целиком, вместе с вложенными папками
(`assets`, `fonts`, `demo`, `v2`, `v3`, `v4`). Отсутствующие папки
создаются на сервере автоматически. Файлы, которые не изменились,
не перезаливаются.

Посмотреть, что будет залито, ничего не меняя:

```bash
./deploy/deploy.sh --dry-run
```

## Что не заливается

`.git`, `.gitignore`, `.DS_Store`, `*.log`, сама папка `deploy`,
`node_modules`.

## Сменить пароль или хостинг

Запустите `./deploy/setup.sh` заново — он предложит перезаписать настройки.
